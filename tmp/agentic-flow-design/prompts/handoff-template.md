# Handoff Template

Use this when one agent hands work to another through GitHub issue comments or an equivalent durable log.

```md
## Handoff

Role: <strategist|tech-lead|builder|validator>
Target Role: <next role>
State: <current workflow state>
Spec / Milestone: <link or id>
Task / Issue: <link or id>

Summary:
- What changed

Evidence:
- Commands, tests, screenshots, PRs, or docs

Open Findings / Risks:
- Remaining concerns or none

Blockers:
- Blocker and required decision, or none

Next Action:
- Exact expected next step
```
