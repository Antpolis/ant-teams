# Security Review

Use this skill for security-sensitive specs, tasks, PRs, and architecture decisions.

Review:

- secrets and credentials
- authn/authz
- data exposure and privacy
- network ingress/egress
- dependency and container supply chain risks
- least privilege
- logging of sensitive data
- infrastructure permissions

Findings should be recorded with GitHub issue comments or PR comments and linked from the GitHub collaboration record.
